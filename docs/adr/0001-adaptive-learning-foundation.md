# ADR-0001：自适应学习基础架构

- 状态：已采用
- 日期：2026-08-15

## 决策

1. 在现有NestJS模块化单体内实现知识图谱、BKT和路径规划。
2. 使用MySQL关系表保存邻接关系，不引入Neo4j。
3. 使用可靠数据库事件连接考试提交与掌握度更新，不增加外部消息队列。
4. 当前版本采用知识图谱+BKT，不将无真实反馈数据的方案称为强化学习。
5. 大模型不得自由生成并执行SQL；赛后查询扩展使用受控的结构化查询计划。

## 原因与后果

比赛规模下关系图遍历可在毫秒级完成，关系表能复用现有Prisma、事务、备份和权限体系。可靠事件避免BKT异常阻断考试，但需要定时重试和失败审计。未来图规模或吞吐量显著增长时，可在保持接口不变的前提下评估专用图数据库或消息队列。
