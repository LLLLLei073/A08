# 知识图谱与BKT自适应学习路径算法说明

## 1. 问题建模

系统将党校学习建模为有向无环知识图谱 `G=(V,E)`：节点表示知识点，边 `u→v` 表示学习 `v` 前应掌握 `u`。课程和试题分别通过多对多关系映射到知识点。每个用户在每个知识点上维护掌握概率 `P(L)∈[0,1]`。

输入包括用户答题证据、知识掌握状态、先修关系、可见课程、课程难度、学习完成状态和必修任务；输出为最多五步、满足先修顺序且附带评分明细的路径。

```mermaid
flowchart LR
  A[党员提交测验] --> B[事务内保存成绩与答题证据]
  B --> C[BKT事件处理器]
  C --> D[更新知识掌握概率]
  D --> E[查找薄弱知识点]
  E --> F[沿图谱回溯未掌握先修知识]
  F --> G[过滤无权限课程]
  G --> H[多指标评分与拓扑排序]
  H --> I[保存可解释路径快照]
  I --> J[党员端与管理端展示]
```

## 2. BKT认知诊断

默认参数：初始掌握 `P(L0)=0.20`，学习转移 `P(T)=0.15`，失误 `P(S)=0.10`。猜测概率按题型取单选 `0.25`、判断 `0.50`、多选 `0.10`。

答对后：

`P(L|正确)=P(L)(1-P(S)) / [P(L)(1-P(S))+(1-P(L))P(G)]`

答错后：

`P(L|错误)=P(L)P(S) / [P(L)P(S)+(1-P(L))(1-P(G))]`

学习转移：

`P(L)'=P(L|观察)+(1-P(L|观察))P(T)`

一道题关联多个知识点时，使用关联权重将完整更新结果与原掌握度线性混合。只有答题正确性作为BKT证据；课程浏览时长不直接代表掌握。

事件以 `quiz:{答题记录ID}:question:{试题ID}` 作为唯一来源键。掌握度更新与事件完成标记在同一数据库事务中执行，重复消费不会二次更新；异常事件最多自动重试五次，且不影响原考试成绩提交。

## 3. 路径规划

掌握阈值设为 `0.65`。算法按掌握度从低到高寻找目标节点，深度优先回溯未掌握的先修节点，生成拓扑顺序。若先修节点未掌握且没有可学内容，算法不会越级推荐其后继节点。

候选内容总分：

`Score=0.35×薄弱度+0.25×先修准备度+0.20×难度匹配+0.10×新颖度+0.10×必修加权`

- 薄弱度：`1-P(L)`。
- 先修准备度：所有直接先修节点掌握度的平均值；无先修节点时为1。
- 目标难度：`clamp(1+4×P(L),1,5)`；难度匹配按差值线性衰减。
- 新颖度：未完成为1，已完成为0。
- 必修加权：属于当前用户可见必修任务为1。

每个知识点只选择得分最高的一项内容，同一内容不重复。输出仍按先修拓扑顺序排列。图谱没有可用候选时，降级返回用户可见的必修任务或公开内容，并明确标记为兜底推荐。

时间复杂度为 `O(V+E+C log C)`，其中 `V` 为知识节点数，`E` 为先修边数，`C` 为候选内容数。

## 4. 数据集说明与评价指标

`prisma/seed-adaptive-demo.ts` 生成12个知识点、15条先修关系、36道知识点试题和最多6类答题轨迹。它是可复现功能演示夹具，不是真实训练集，不用于宣称学习成绩提升或预测准确率。

当前评价指标：

- 路径先修约束满足率：目标100%。
- 路径内容与知识点关联完整率：目标100%。
- 推荐解释字段完整率：目标100%。
- 重复事件二次更新次数：目标0。
- 200节点、近1000条先修关系的纯规划P95：本地/CI目标小于300ms。

## 5. 基线对比与调优边界

| 维度 | 原分类/错题频次推荐 | 知识图谱+BKT路径 |
|---|---|---|
| 冷启动 | 依赖学习历史 | 使用知识点初始掌握度 |
| 先修约束 | 不保证 | 强制拓扑顺序 |
| 动态更新 | 分类统计变化 | 每次答题证据更新掌握概率 |
| 可解释性 | 文本推荐理由 | 掌握度、先修、难度和五项评分 |
| 可审计性 | 推荐结果缓存 | 事件与路径快照可追溯 |

第一版参数固定并带算法版本号。积累真实、脱敏的学习日志后，使用离线回放、参数网格搜索和按组织分层验证调优BKT参数；只有在反馈样本充分且离线策略评估通过后，才考虑LinUCB等上下文老虎机方法。
