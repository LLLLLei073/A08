# 数智党校系统生产化加固实施计划

> 本计划落实 2026-08-13 全项目审查结论。所有修改均在现有脏工作区上做最小增量，不重置或覆盖用户改动。

## 任务 1：鉴权响应与持久会话失效

- 修改双 Prisma schema：为 `User` 添加 `securityVersion`。
- 登录响应移除令牌；`JwtAuthGuard` 以数据库用户状态和版本为准。
- 修改密码、强制设置密码及后台账户关键字段变更时递增版本。
- 强制改密用户仅可进入改密所需接口。
- 验证：服务端类型检查和鉴权单元测试。

## 任务 2：支部数据隔离

- 统计总览按管理员/支部书记范围计算。
- AI 查询工具按组织过滤，并实现时间范围过滤。
- AI 报告列表、详情、发布、删除按组织授权。
- 移除统计总览的全局 HTTP 缓存。
- 验证：组织越权单元测试和服务端类型检查。

## 任务 3：考试生命周期

- `start` 创建或恢复未提交答题记录并返回剩余秒数。
- `submit` 更新该记录并校验考试窗口、个人时限和并发重复提交。
- 我的考试和结果接口区分“已开始”与“已提交”。
- 验证：开始恢复、超时、重复提交测试。

## 任务 4：学习数据可信度与趋势

- 新增 `LearningDailyStat` 模型并保持 SQLite/MySQL schema 一致。
- 服务端限制可接受时长增量，用可信时长决定完成状态。
- 统计趋势改为按日累计数据。
- 验证：伪造大时长被截断、正常心跳累加测试。

## 任务 5：输入与文件边界

- 为 PATCH DTO 和分页筛选查询补齐转换、类型、范围与白名单校验。
- 导入文件增加扩展名/MIME/文件头校验。
- ZIP/PDF 解压增加输出大小与累计预算。
- 验证：非法参数和压缩炸弹防护测试。

## 任务 6：运行安全

- 生产环境缺少 CORS 白名单时禁用跨域。
- 健康检查在数据库或 Redis 异常时返回 503。
- 登录接口增加独立限流。
- 随机初始密码改用密码学安全随机源。
- 验证：启动配置与关键服务测试。

## 任务 7：迁移与部署

- 生成正式 MySQL 初始迁移并提交迁移锁文件。
- Windows 部署脚本改为 `prisma migrate deploy`，不覆盖 schema。
- 生产 seed 要求显式提供账户密码。
- 验证：两个 schema validate、迁移 SQL 检查、部署脚本静态检查。

## 任务 8：工程基线与文档

- 建立 ESLint flat config 并声明依赖。
- 扩充根 README：架构、启动、配置、测试、部署、默认账户安全说明。
- 完善 `.gitignore`，防止临时文件和构建产物再次进入版本库。
- 验证：lint、全包类型检查、单元测试和生产构建。
