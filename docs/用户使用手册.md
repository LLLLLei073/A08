## 一、系统概述

数智党校学习系统面向基层党组织，提供「**学—练—考—评**」一体化的在线学习闭环：

| 环节 | 党员侧（移动端） | 管理侧（后台） |
|------|----------------|---------------|
| **学** | 浏览文章 / 视频，记录学习进度 | 维护学习内容、发布学习任务 |
| **练** | 参加练习测验，自动归集错题 | 维护题库、组卷、发布测验 |
| **考** | 参加正式考试，实时判分 | 设置考试窗口、时长、范围 |
| **评** | 查看 AI 生成的个性化周报 | 用自然语言问数据、看统计大屏 |

系统内置 **DeepSeek 大模型** 三项 AI 能力：

1. **个性化学习推荐**——根据学习轨迹、错题、薄弱点推送内容；
2. **自然语言数据查询（NL2Chart）**——用大白话问学习数据，自动返回文字结论 + 图表；
3. **AI 综合评价报告**——每周为每位党员生成能力雷达图、评语与改进建议。

## 二、访问入口与账号

部署完成后，浏览器打开以下地址（将 `IP` 替换为实际服务器地址）：

| 入口 | 地址 | 使用人 |
|------|------|--------|
| 移动端学习平台（H5） | `http://IP:3000/` | 党员、支部书记 |
| 管理后台（PC） | `http://IP:3000/admin/` | 管理员、支部书记 |
| API 健康检查 | `http://IP:3000/api/health` | 运维 |

> 移动端为自适应 H5，可在手机浏览器直接访问，也可在企业微信 / 钉钉中作为网页应用嵌入。

**默认演示账号**（首次部署由种子数据生成，请及时修改密码）：

| 角色 | 用户名 | 密码 | 说明 |
|------|--------|------|------|
| 系统管理员 | `admin` | 由部署环境变量设置（开发默认 `Admin@123456`） | 拥有全部后台权限，含 AI 配置 |
| 支部书记 | `secretary1` | 由部署环境变量设置（开发默认 `Secretary@123456`） | 可管理本支部，无 AI 配置权限 |
| 党员 | `member1` ~ `member6` | `Party@123456` | 仅移动端 |

## 四、移动端（党员 / 支部书记）使用指南

### 4.1 登录与登出

1. 手机浏览器打开移动端地址 `http://IP:3000/`。
2. 进入「我的」页，点击登录，输入**用户名**与**密码**。
3. 登录态由 HttpOnly Cookie 维持，关闭页面或扫码后免重复登录；如需退出，在「我的」页点击「退出登录」。

### 4.2 首页与 AI 智能推荐

首页顶部展示问候语与学习标语，下方分为两块：

- **AI 为你推荐**：系统基于你近 30 天的已学分类、错题分类、测验低分分类，调用 DeepSeek 智能匹配 Top 5 公共内容，每张卡片显示分类、推荐理由。点击卡片直接进入学习详情。
  - 若提示「暂无推荐」，说明学习数据尚少，先学习几篇内容后即可获得推荐。
- **学习内容**：按分类（全部 + 各分类 Tab）分页列出内容卡片，区分「视频 / 文章」类型、分类、标签。点击卡片进入详情。

### 4.3 学习内容（文章 / 视频）

进入内容详情页：

- **文章**：以 Markdown 渲染正文，顶部显示约多少字、预计阅读时长；阅读进度实时记录（约 5 字/秒）。**满足最短阅读时长后**才可「标记完成」；未达标时按钮提示「阅读时长不足」。
- **视频**：内嵌播放器，进度按观看百分比计算；**需看完视频**方可标记完成。
- 学习进度会在后台自动上报（每 5 秒一次），中途退出也会补报，再次进入可续看。
- 完成后该内容计入任务进度与学习统计，并作为 AI 推荐 / 评价报告的输入。

### 4.4 学习任务

「任务」Tab 列出你所在支部发布给你的任务（含「全部成员」任务与指定到你的任务）：

- 每项任务显示完成百分比、截止时间、包含的学习内容清单。
- 展开可看到每个内容的完成状态；点击内容项可跳转学习。
- 任务进度 = 所含内容完成情况的平均，全部完成即 100%。

### 4.5 测验答题

「测验」Tab 列出可参加的练习测验与正式考试：

1. 点击进入后进入作答页，顶部显示**剩余时间**（取「测验时长」与「考试窗口剩余时间」的较小值）与题目总数。
2. 题型支持：
   - **单选**：点选项直接选中；
   - **多选**：可勾选多个，答案按字母排序后判分（如 `BCA` 与 `ABC` 等价）；
   - **判断**：选「正确 / 错误」。
3. 点击「提交测验」：若有未答题会二次确认；提交后即时判分，提示「得分 / 总分」及是否通过。
4. 时间耗尽自动提交。提交后可查看「答题结果」页（错题解析、正确答案）。
5. 判分规则（与管理端一致）：多选排序后大写比较、判断大小写不敏感、单选大写比较。

### 4.6 AI 综合评价报告

「我的 → AI 综合评价报告」或首页入口进入：

- 系统为每位党员**每周生成一次**综合报告（同周重复访问返回缓存，不重复消耗额度）。
- 报告包含：
  - **综合评分**（学习频率 30% + 测验成绩 30% + 考试成绩 40% 加权）；
  - **能力雷达图**（学习频率 / 测验成绩 / 考试成绩 / 知识掌握）；
  - **总体评语**、**优势**、**待改进**、**改进建议**（由 DeepSeek 基于真实学习数据生成）。
- 可通过「报告历史」查看过往周报对比。

### 4.7 个人中心

「我的」页展示头像、姓名、所属支部，以及入口：学习任务、测验、AI 报告、退出登录等。

## 五、管理后台（管理员 / 支部书记）使用指南

> 后台为 PC 端，使用 Element Plus 组件。左侧菜单即各功能模块，顶部显示当前用户与角色。

### 5.1 工作台

登录后默认进入「工作台」，聚合关键指标（党员数、学习时长、任务/测验完成情况、近期动态），便于一眼掌握整体态势。

### 5.2 组织架构管理

以树形展示组织（如：党委 → 党总支 → 支部）。可：

- 新增 / 编辑 / 删除组织节点；
- 支持多级嵌套，支部为最末级（level=2）；
- 人员、任务、测验均挂在支部下。

### 5.3 人员管理

- 维护党员 / 支部书记账号：新增、编辑、停用、重置密码。
- 支持按支部筛选、按角色筛选（ADMIN / SECRETARY / MEMBER）。
- 发布任务 / 测验选择「指定人员」时，从此处拉取该支部党员列表。

### 5.4 学习内容管理

路径：学习内容 → 列表。

- **筛选**：按关键词、分类、类型（文章 / 视频）查询。
- **新增 / 编辑**（弹窗表单）：
  - 标题、类型（文章 / 视频）、分类（如：党章 / 党史 / 时政 / 理论）、标签；
  - 文章：使用 Markdown 编辑器撰写正文（已禁用原始 HTML，防 XSS）；
  - 视频：点击上传视频文件，可填视频时长（秒）；
  - **设为公共**：开启后该内容对所有党员可见，并纳入 AI 推荐候选池。
- **删除**：二次确认后删除。

### 5.5 题库管理

路径：题库管理。

- **筛选**：按题干、题型（单选 / 多选 / 判断）、分类查询。
- **新增题目**：
  - 新题统一为判断题，填写题干、分类后直接选择“正确”或“错误”；
  - 不需要维护多个选项；
  - 解析为选填项，可在作答结果页展示；
  - 已有单选 / 多选题仍可查看和编辑。
- **批量导入题目**：
  1. 点击「下载模板」，选择 Excel 或 CSV 模板；
  2. 每行填写一道题目，答案填写“正确”或“错误”；
  3. 点击「批量导入」，上传 `.xlsx` 或 UTF-8 `.csv` 文件；
  4. 系统在本机解析并返回「成功 N 条 / 失败 M 条」，不调用 AI。

### 5.6 试卷管理

- 维护试卷：设置试卷标题、所含题目（从题库勾选）、各题分值、试卷总分、建议做题时长。
- 试卷是测验的载体；发布测验时选择对应试卷即可。
- 试卷的「做题时长」会作为测验时长的基准（练习测验 ×2，正式考试不变，详见 5.7）。

### 5.7 测验管理

路径：测验管理 → 发布测验。

表单字段：

- **试卷**：从已建试卷中选择（显示总分）；
- **类型**：练习测验 / 正式考试；
- **目标支部**：管理员可选任意支部，支部书记锁定本支部；
- **开始 / 结束时间**：考试窗口；
- **时长（分钟）**：系统按所选试卷做题时长自动推导（练习 ×2、正式不变），只读展示；
- **参与对象**：全部成员 / 指定人员（指定时从本支部党员中多选）。

发布后，移动端对应党员即可在「测验」中看到并参加。

### 5.8 学习任务管理

路径：学习任务 → 发布任务。

表单字段：

- **任务标题**、**所属支部**（支部书记锁定本支部）；
- **截止时间**；
- **学习内容**：从内容库多选；
- **参与对象**：全部成员 / 指定人员。

党员侧「任务」页按完成度实时汇总，管理员可在统计中查看整体完成率。

### 5.9 数据统计

- 多维度数据看板：学习时长、任务完成率、测验平均分、考试通过率、党员活跃度等；
- 支持按支部、时间段筛选与对比，结果可用于述职汇报与督促学习。

### 5.10 AI 自然语言数据查询

路径：AI 数据查询（DeepSeek）。

- 在对话框输入**自然语言问题**，例如：
  - 「今年三支部学习完成率」
  - 「各支部测验平均分对比」
  - 「全部支部党员数」
  - 「各支部考试通过率」
- 系统通过 Function Calling 识别意图 → 查询真实数据 → 由 DeepSeek 生成**文字结论 + ECharts 图表**（仪表盘 / 柱状 / 折线 / 雷达等）。
- 页面提供建议问法按钮，点击即可快速提问；历史对话可连续追问。
- 支持查询的指标：学习时长、任务完成率、测验平均分、考试通过率、党员数；支持「某支部 / 全部」「今年 / 近 30 天 / 全部」等范围。

### 5.11 AI 模型配置（仅管理员）

路径：AI 配置（左侧菜单，仅 ADMIN 可见）。

- 填写 **API Key**、**API 基础地址**、**对话模型**、**推理模型**（默认 deepseek-chat / deepseek-reasoner）。
- 点击「测试连接」验证可用性；点击「保存配置」即时生效，**无需重启服务**。
- 未配置或 Key 无效时，三项 AI 功能（智能推荐 / 数据查询 / 评价报告）将不可用，页面会给出明确告警。

## 六、AI 能力总览

| 能力 | 触发位置 | 输入 | 输出 | 配置依赖 |
|------|---------|------|------|---------|
| 个性化学习推荐 | 移动端首页 | 用户近 30 天学习 / 错题 / 低分分类 | Top 5 内容卡片 + 理由 | DeepSeek 已配置 |
| 自然语言数据查询 | 后台 AI 数据查询 | 自然语言问题 | 文字结论 + ECharts 图表 | DeepSeek 已配置 |
| AI 综合评价报告 | 移动端 AI 报告 | 用户学习 / 测验 / 考试 / 错题数据 | 评分 + 雷达图 + 评语建议 | DeepSeek 已配置 |

> 所有 AI 结果均基于**系统真实数据**生成，不含虚构；推荐与报告均带缓存（推荐 1 小时、报告按周），避免重复消耗。若 DeepSeek 超时，移动端首页推荐会自动降级为空（不阻塞其它内容加载）。
