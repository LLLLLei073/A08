# 微信小程序迁移规划目录

本文件夹**仅包含规划文档，不修改项目任何原有代码**。

## 文件说明

- **`任务清单.md`** —— 主文档。包含：项目现状评估、4 个关键决策点、分 5 个阶段的完整任务清单（含复选框）、接口映射表、风险与工作量预估。

## 核心结论速览

1. **后端（NestJS）可复用**，但当前 `http://IP:3000` 不能用于小程序，必须先换成「已备案 HTTPS 域名 + 微信后台 request 合法域名白名单」。
2. **移动端（Vue3 H5）必须重写**为原生小程序（WXML/WXSS/JS），放在独立文件夹，零耦合原 monorepo。
3. **推荐登录方案**：先复用现有 `/auth/login`（零后端改造）上线，后续再加微信一键登录（新增接口，不改动既有逻辑）。
4. 小程序只做**党员学习端**，对应 `mobile` 包功能，不接管理员/书记接口。
5. 全程不碰 `server` / `admin` / `mobile` / `shared` 代码，预计 2–3 周上线首个版本。

## 如何开始

1. 先确认「二、关键决策」里的 4 个点（尤其域名备案和登录方案）。
2. 按「三 → 七」阶段顺序推进，每阶段任务打勾推进即可。
